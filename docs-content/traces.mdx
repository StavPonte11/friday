## Why Traces?

Building agents without observability is like flying blind. If an agent loops infinitely, hallucinates a response, or incorrectly maps a tool argument, you need to know *exactly* what prompted the error.

FRIDAY Traces is our answer: a built-in telemetry module fully integrated with **Langfuse**. Every agent interaction is automatically traced from start to finish.

<Callout type="info">
  We trace every node transition in the LangGraph, providing visibility into the "thought process" of the agent before it executes a tool.
</Callout>

## Working with Traces

Whenever the FAB (Floating Action Button) Agent is invoked via the Command Bar, a Trace ID is generated. 

1. **Graph Nodes:** The trace shows transitions between nodes: `rag`, `agent`, `tools`.
2. **Generations:** Any LLM payload is logged with input/output, model metadata, token counts, and cost estimation via Langfuse.
3. **Observations:** Tool outputs are captured as observations, allowing you to debug exactly what data the agent received from the database.
4. **Trace Dashboard:** Accessible via `/traces`, this dashboard gives team leads a macro-view of AI health, success rates, and latency.

## Integrating Custom Agents

You can bind your own custom background workers to the trace framework. Ensure your environment has `LANGFUSE_PUBLIC_KEY` exported, and simply wrap your functional calls with the `@friday/traces` decorator.
