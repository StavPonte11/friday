## Welcome to F.R.I.D.A.Y

FRIDAY is a comprehensive, agentic execution environment designed for modern product development teams. Rather than scattering your work across a dozen different tools for task management, observability, agent workflows, and documentation, FRIDAY centralizes the entire lifecycle into a single **"Product-Native"** platform.

<Callout type="tip">
  "Product-Native" means that features like search, documentation, and agent execution don't feel bolted-on. They are designed to feel like first-class citizens embedded directly into your workflow.
</Callout>

## Core Modules

F.R.I.D.A.Y consists of three major pillars:

1. **FRIDAY PM:** A modern project management experience featuring Kanban boards, auto-generated Gantt timelines, Calendar views, and deep collaboration utilities (Mentions, Presence).
2. **FRIDAY Traces:** Observability and debugging for LLM applications. Seamless integration with Langfuse allows you to inspect LLM inputs, outputs, tokens, and latency spanning across your background workers and UI agents.
3. **FRIDAY Agents:** The intelligence layer. With full MCP (Model Context Protocol) support and native background workers mapped to RabbitMQ, FRIDAY executes tasks asynchronously on your behalf—like parsing github webhooks or fetching emails.

## Why FRIDAY?

We set out to build an execution environment that goes beyond standard issue tracking. With built-in **Semantic Search** using `pgvector` and an **Insights Engine** powered by Large Language Models, FRIDAY understands not just *what* issues exist, but *how* the team is performing, automatically analyzing cycle times and bottlenecks.
